### 프로젝트 주차별 일정

| 주차   | 주요 내용 |
|--------|-----------|
| **1주차** | 프로젝트 주제 선정 및 데이터셋 조사<br>사용 목적 및 문제 정의, 공개 이미지 데이터셋 조사 및 수집 |
| **2주차** | 데이터셋 구성 및 중복 확인<br>학습/검증/평가 데이터 분리, 이미지 해시 비교로 중복 여부 확인 |
| **3주차** | 데이터 전처리<br>이미지 크기 통일, 정규화, 라벨링 방식 통일 및 저장 포맷 설정 |
| **4주차** | CNN 모델 설계 |
| **5주차** | CNN,LSTM 모델 설계 |
| **6주차** | 모델 개선, 학습률 및 배치 사이즈 실험<br>정확도 및 손실 비교 |
| **7주차** | 평가 및 오류 분석 |
| **8주차** | 다양한 케이스 테스트<br>전체 결과 요약 정리 및 성능 개선 |
| **9주차** | 최종 보고서 작성 |

### 브랜치 설명

| 주차   | 주요 내용 |
|--------|-----------|
| **data** | 데이터 전처리 코드 |
| **learning** | 모델 학습 코드 |
| **model** | 학습이 완료된 모델 파일 |
| **real_test** | 직접 촬영한 시연 영상 기반 데이터 및 모델 테스트 코드 |
