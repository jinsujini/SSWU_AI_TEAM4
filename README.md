### 역할 분담표

| 이름     | 주요 역할                        | 상세 업무 |
|----------|----------------------------------|-----------|
| **시현** | 데이터 처리 총괄 + 시각화       | - 데이터셋 정리 및 중복 제거<br> - 불량 이미지 필터링<br> - 데이터 증강 (회전, 크롭, 스케일링 등)<br> - 관절 시각화 / 혼동행렬 등 결과 리포트 |
| **수빈** | 모델 설계 및 학습 담당           | - CNN 기반 스켈레톤 이미지 인식 모델 설계<br> - LSTM 구조 통합 및 시계열 흐름 반영<br> - 하이퍼파라미터 조정 (학습률, 배치 사이즈 등)<br> - 학습 결과 시각화 및 정확도 개선 |
| **수진** | 프로젝트 기획 & 보고서 담당      | - 전체 프로젝트 설계 흐름 정리<br> - 필라테스 모델 필요성 및 기술 차별성 정리<br> - 역할 분담 정리 및 타임라인 관리<br> - 발표자료 및 최종 보고서 작성 |
| **민선** | 성능 평가 및 피드백 로직 구현     | - 동작 분류 정확도 평가 (혼동행렬 기반)<br> - 관절 각도 추정 및 기준 각도 오차 계산<br> - 감점 사유 태깅 및 피드백 생성 로직 구현<br> - 실시간 피드백 로직 통합 테스트 |

### 프로젝트 주차별 일정

| 주차   | 주요 내용 |
|--------|-----------|
| **1주차** | 프로젝트 주제 선정 및 데이터셋 조사<br>사용 목적 및 문제 정의, 공개 이미지 데이터셋 조사 및 수집 |
| **2주차** | 데이터셋 구성 및 중복 확인<br>학습/검증/평가 데이터 분리, 이미지 해시 비교로 중복 여부 확인 |
| **3주차** | 데이터 전처리<br>이미지 크기 통일, 정규화, 라벨링 방식 통일 및 저장 포맷 설정 |
| **4주차** | CNN 모델 설계 |
| **5주차** | CNN,LSTM 모델 설계 |
| **6주차** | 모델 개선, 학습률 및 배치 사이즈 실험<br>정확도 및 손실 비교 |
| **7주차** | 평가 및 오류 분석 |
| **8주차** | 다양한 케이스 테스트<br>전체 결과 요약 정리 및 성능 개선 |
| **9주차** | 최종 보고서 작성 |
